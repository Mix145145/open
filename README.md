# Tuposcan (Raspberry Pi 4B + IMX477)

Приложение управляет станком (G-code) и камерой для сканирования области **100×100 мм** с автокалибровкой FOV по ArUco/AprilTag.

## Архитектура

- `motion_controller.py` — управление станком: `home()`, `move_abs()`, `move_xy()`, `wait()`, таймауты/проверка `ok`.
- `camera_manager.py` — доступ к камере: `snap()`, `warm_up()`, `set_exposure()`.
- `fov_calibrator.py` — статистическая калибровка FOV (несколько кадров, автоподбор словаря и препроцессинг).
- `scan_planner.py` — расчёт шага, сетки и траектории змейкой для области 100×100 мм.
- `main.py` — UI и orchestration сервисов.

## Основной workflow

1. Подключить serial и камеру.
2. Выбрать/ввести высоту Z.
3. Нажать **«В центр + на Z»** (последовательность: `G90`, `G28`, центр `X54 Y110`, затем `Z`).
4. Подкрутить фокус механически.
5. Нажать **«Калибровать все разрешения»** — автоматически создаются профили для `1920x1080`, `2560x1440`, `3840x2160`.
6. Выбрать качество и нажать **«Сканировать»**.

FOV/step оператор вручную не вводит: они рассчитываются автоматически по калибровке.

## Конфиг

`aruco_calib.json` хранится в формате:

```json
{
  "marker_size_mm": 5.0,
  "profiles": {
    "83.00": {
      "1920x1080": {"fovX": 30.12, "fovY": 16.95, "mm_per_px": 0.0157, "dict": "DICT_4X4_50", "quality": 1234.5}
    }
  },
  "last_z": 83.0,
  "last_resolution": "2560x1440",
  "overlap": 0.2
}
```

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 main.py
```
